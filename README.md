#### 重点1：美区和国区AppStore的区别

主要有2个明显的区别：

1、国区的AppStore是无法搜索Tiktok、Telegram、Instangram、X、Facebook这类国外应用的，你登录的AppleID如果能搜索到这些应用，说明就是国外的AppStore。

2、外区的AppStore底部多了一个菜单「Arcade」

![](https://files.mdnice.com/user/4562/e6d61b50-e9cb-4464-9328-90b921a7cd41.jpg)

美区的AppStore是有这个菜单栏的，其他外区的AppStore就不确定100%有了。

####  重点2：登录AppStore

重点提醒：

1、不需要退出设置里的 iCloud 原账号。

2、千万不要从设置里面登录（也就是登录iClound），否则你的设备有可能被锁死！


使用这种外区AppleID也非常简单， 打开App Store > 点击头像 > 拉到最下面，点击退出登录。


![](https://files.mdnice.com/user/4562/7158b7d6-3c56-420e-a6da-066d574526ab.png)


![](https://files.mdnice.com/user/4562/bbbb85db-a633-4127-a5a6-7c78abe509c6.png)
